# MD View Privacy Policy

_Last updated: 2026-10-02_

MD View is a free Markdown reader for Chrome. It is built to work entirely on your computer.

## The short version

- MD View does not collect personal information.
- MD View does not collect analytics.
- MD View does not track browsing.
- MD View does not upload Markdown files.
- Markdown files are processed locally in the browser.
- MD View does not sell or share user data.
- MD View does not use advertising.

## What stays on your computer

When you open a file, MD View reads it with the browser's standard File API, turns it into a formatted page, and shows it. The file name, its contents, your searches and anything you copy are held in memory only while the tab is open. None of it is written to storage and none of it is sent anywhere.

MD View has no backend, no account system and no server of its own. It makes no network requests while you read. All code, including every library, is bundled inside the extension; nothing is loaded from a CDN or other remote host.

## What MD View stores

MD View keeps a few preferences in your browser's local storage for this extension only:

- your theme choice (System, Light or Dark)
- whether the contents sidebar is open
- whether support reminders are on
- a count of how many Markdown files you have opened, and the count at which the optional support reminder may next appear

The count is a single number. It is never transmitted, never used for analytics, and contains nothing about which files you opened. You can clear all of this by removing the extension or clearing the extension's site data.

## Images in documents

A Markdown file can link to images hosted on other websites. MD View blocks these by default so that reading a document never contacts another server. If you click **Load images**, your browser requests those images from the sites that host them, and those sites can see your IP address as they would for any web page. MD View sends no referrer when it does this.

## Permissions

MD View requests no browser permissions. It does not read your browsing history, your tabs, the pages you visit, your clipboard contents, or your files other than the ones you choose.

## Supporting the project

**Support MD View** is optional and never unlocks features. Choosing it opens an external website in a new tab. That website is run by a third-party provider (such as Ko-fi, GitHub Sponsors or Buy Me a Coffee) and has its own privacy policy. MD View never processes payment information.

## Children

MD View collects no data from anyone, including children.

## Changes

If this policy changes, the new version will be published in this file with an updated date.
